# STUDYMATE
StudyMate is a student-focused study platform that helps students organize tasks, notes, schedules, progress, and focused study sessions in one place.
**FEATURES**:
Study resources for different subjects.
Notes and learning section.
Timer to focus.
Simple and clean student dashboard.
beginner friendly interface

**TECHNOLOGY USED**
. HTML
. CSS
. Javascript

**PURPOSE**
The purpose of studymate is to create a simple digital study companion that helps students keep their learning materials organized and makes studying easier.
